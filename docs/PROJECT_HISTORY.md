## 2026-10-19 — 시작과 실무 앱의 방향
- 사용자는 자신의 **퍼스트현대 공인중개사 사무실 + 가족 전용 Android 설치형 앱**을 요구. 서비스 판매용이 아니라 가족 업무에 사용, 가능한 무료 운영. 먼저 업무 흐름 논의 후 점진적으로 실제 코드로 구현.
- 주 기능: 송도동 아파트 실거래가, 새로 확인된 거래, 뉴스, 아파트 기본정보/평형/학교, 업무 메모, 관리자/가족 권한 분리. 인천 연수구에서 **송도동만** 정확히 걸러낼 것.
- APK WebView + GitHub Pages가 아닌 **GitHub 공개 JSON**을 원격 조회하는 무료 아키텍처를 채택. 가족 휴대폰은 동일 공개 데이터를 조회하고, 사무실 업무 메모는 기기에 남음.
- 국토부 실거래 수집은 최근 12개월 매매/전세/월세; 취소거래 포함. '새 소식'의 날짜는 계약일도 정부 신고일도 아닌 **이전 스냅샷 대비 새로 발견한 날짜**라고 명확히 결정.
- 가족용 앱의 불필요한 관리자 설정 메뉴를 숨김. 초기에는 13개 관심 단지, 이후 14번째 센트럴파크푸르지오 추가.
- K-apt 공식 정보/네이버페이부동산 참고값 대조, 히스토리 표시에 실무 필드 우선. 학교 배정은 데이터가 검증되기 전 임의 입력하지 않음.
- 카카오 지도 지역 주변시설: 사용자가 Kakao ON/REST key, Cloudflare Worker `firsthyundai-kakao.jwj2477.workers.dev` 설정을 했던 이력. 키 값은 절대 문서에 넣지 않음.

5. **"퍼팍/마뷰 같은 이름이라도 단지(블럭)로 구분"** 동 첫 두 자리 블럭 추론은 알려진 범위에서만.

## 운영 인프라/문제 조사 연혁
- 국토부 아파트 거래 및 K-apt 인증/승인 데이터는 GitHub Secrets `DATA_GO_KR_SERVICE_KEY`와 서비스별 승인 필요.
- Gemini `GEMINI_API_KEY`, Groq `GROQ_API_KEY`, NEIS `NEIS_EDU_KEY` (값은 기록하지 않는다). Cloudflare 카카오 Worker는 앱에 키를 삽입하지 않는 프록시 구조. 학교 API는 호출 빈도/서버 상태 제약.
- NEIS 관련 GitHub #17 실패 `exit code 2` → 실제 HTTP 500 확인. 크기 100→25→5 페이지 변경에도 실패. 공개 샘플키, 잘못된 키, 실제 키, XML, 별도 나이스 API 호출까지 모두 HTTP 500. 사용자가 Secret 재입력 후 새 실행에서도 동일. **이것은 인증키가 맞다는 증명도 틀렸다는 증명도 아님.** 최신 `data/public_services.json`의 `schools.state`와 별도로 판단.
- 과거 GitHub Actions 간헐적 Maven 의존성 403·동시 Release 태그 생성 실패 등이 있었다. 실패한 오래된 빌드만 보고 최신 APK가 실패했다고 판단 금지. **최종 run·tag·assets를 직접 확인**.
