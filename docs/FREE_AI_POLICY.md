# 무료 AI 운영·추가 도입 기준

사용자 승인: 2026-10-30. 현재 기능 유지, 무료만 사용, 유의미한 추가 효과가 예상되는 제공자만 추가.

## 현재 적용
- Gemini: 기존 기사 본문 요약과 상담 체크포인트. 입력 재사용, 누락만 묶음 재시도, 한도/인증 거절 뒤 해당 수집 실행 중단.
- Groq: Gemini가 처리하지 못한 본문 요약 및 중요 기사 제한 검토, 선택형 상담 체크포인트 fallback.
- 공개 뉴스만 전송한다. 계약 원문·계좌·고객·공유메모·개인 일정을 새로운 외부 AI로 보내지 않는다.
- 새 유료 엔드포인트, 모델 자동 교체, 결제 업그레이드, 유료 자동 충전은 구현하지 않는다.
- API 키만으로 실제 결제 등급을 확인할 수 없다. 기존 Gemini 프로젝트와 Groq 조직의 Free 등급 유지가 전제다. 호출 상한이나 429 중단 처리가 유료 계정에서의 무과금을 보증하지 않는다.
- 한도가 소진되면 기존 요약·실거래·계약·메모·일정·날씨 기능을 계속 제공하며 선택형 새 AI 생성만 일시 중지한다.

## 추가 도입 심사
1. 최근 3회 이상의 실제 수집 결과에서 기존 두 제공자의 누락/장애 구간을 먼저 확인한다. 원문 미확보는 새 생성형 AI를 붙여도 해결되지 않으므로 분리한다.
2. 공개 기사만으로 최소 12개 동일 평가 표본을 구성한다. 정책 확정/검토 구분, 숫자, 날짜, 한국어 가독성, JSON 형식, 기존 실패 복구를 평가한다.
3. 제안 기준: 기존 두 AI에서 실패한 표본 중 최소 3개를 추가 복구하고 근거 없는 숫자·확정 표현이 없어야 한다. 동급 출력만 반복하면 추가하지 않는다. 표본 통과는 전반적 무오류 보증이 아니다.
4. 일회성 체험·구매·카드 필수 모델은 제외한다. 무료 요금제에서 한도 초과가 실패로 끝나는지 확인하고 유료 fallback을 금지한다.
5. 최초 운영은 두 AI 모두 실패한 본문에만 작은 호출 예산으로 적용. 실패 시 기존 동작 유지. 키 확보와 실제 검증 전에는 연결 완료로 안내하지 않는다.
6. 새 키가 필요하면 Secret 이름과 등록 위치만 안내한다. 사용자에게 채팅에 키 원문을 쓰도록 요청하지 않는다.
