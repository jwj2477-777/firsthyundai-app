- [x] 앱 하단의 하드코딩 `v1.10` 재발 금지. **현재 휴대폰에 설치된 APK**의 Android `PackageInfo.versionName/versionCode`에서 버전·빌드 표기. 다운로드 가능한 최신 공개 릴리스와 기기 설치 버전을 혼동하지 않기.
