관리자 · 비밀번호 관리

가족용과 관리자용 비밀번호는 서로 독립적입니다.

관리자 전용 비밀번호

관리자 화면에 들어갈 때는 가족 로그인 코드가 아닌 별도의 관리자 비밀번호를 확인합니다. 관리자 모드는 앱을 종료하면 자동으로 해제됩니다.

관리자 비밀번호는 공개 GitHub 파일이나 앱에 직접 입력해 저장하지 않습니다. GitHub 로그인 후 비공개 Secret에서만 변경하세요. 가족 코드와 다른 길고 무작위한 12~64자 비밀번호가 필요합니다. 16자 이상 권장합니다.

① 관리자 비밀번호 등록·변경

GitHub → Settings → Secrets and variables → Actions에서 FIRSTHYUNDAI_ADMIN_CODE를 새로 추가하거나 편집합니다.

관리자 비밀번호 설정 열기 ↗

② 관리자 정책 적용

Publish Administrator Access Policy에서 Run workflow를 실행합니다. 완료된 뒤 새 관리자 비밀번호로 로그인할 수 있습니다.

관리자 비밀번호 적용하기 ↗

관리자 비밀번호를 변경하면 이미 열려 있던 관리자 화면은 다음 온라인 확인 시 가족 모드로 돌아갑니다. 온라인 보안 정책이 없으면 관리자 전환을 허용하지 않습니다.

가족용 보안코드 변경

한 번 인증한 휴대폰은 평소 자동으로 열리고, 관리자가 코드를 바꾸면 새 코드를 다시 입력합니다.

이 앱이나 공개 GitHub 파일에 보안코드를 입력하지 마세요. 실제 변경은 GitHub 비공개 Secret에서 진행합니다. 영문·숫자·기호 12자 이상의 추측하기 어려운 코드를 권장합니다.

① 새로운 가족 코드 등록

GitHub에 로그인해 FIRSTHYUNDAI_ACCESS_CODE Secret을 편집하고 새 보안코드를 저장하세요.

GitHub 보안코드 설정 열기 ↗

② 가족 휴대폰에 변경 적용

아래 링크에서 Run workflow → Run workflow를 누르면 기존 APK를 다시 설치하지 않고도 새 코드로 인증 상태가 바뀝니다.

새 보안코드 적용하기 ↗

③ 다음 실행 때 새 코드 인증

각 휴대폰이 온라인 정책을 확인할 때 코드 변경을 감지합니다. 오프라인은 최근 확인 정책으로 최대 24시간 이용 가능합니다.

이 휴대폰의 인증정책을 확인하는 중입니다.

보안 한계

가족 코드만 알고 있다면 관리자 모드로 들어갈 수 없게 분리했습니다. 그러나 APK와 검증용 코드가 공개되는 구조여서 서버 기반 계정·기기 인증만큼 강한 복제 방지는 아닙니다. 휴대폰별 원격 차단 기능은 아직 없습니다.

두 비밀번호의 원문은 GitHub 비공개 Secret에만 존재하고, 공개 저장소에는 각 비밀번호의 PBKDF2 검증 정보만 게시됩니다. 공개 검증 정보는 오프라인 추측 공격 대상이므로 특히 관리자 비밀번호는 16자 이상 무작위 문자열을 권장합니다.
